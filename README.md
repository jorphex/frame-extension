# Frame Community Companion

> [!IMPORTANT]
> This repository has been superseded by
> [Wren Companion](https://github.com/jorphex/wren-companion). Active browser
> companion development, releases, documentation, support, and security guidance
> now live there.

Wren Companion connects browser-based Ethereum and EVM dapps to the
[Wren desktop wallet](https://github.com/jorphex/wren).

This repository and its existing releases remain available as historical
reference. New installations and contributions should use Wren Companion.
